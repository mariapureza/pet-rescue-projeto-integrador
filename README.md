# Pet Rescue

Projeto desenvolvido para a disciplina de **Projeto Integrador VI-A**, do curso de **Análise e Desenvolvimento de Sistemas da Universidade Católica de Pelotas (UCPel)**.

## Sobre o projeto

O **Pet Rescue** é uma plataforma web voltada à adoção responsável e à gestão de animais resgatados.

A proposta é disponibilizar uma área pública para consulta de animais disponíveis para adoção e uma área administrativa destinada ao gerenciamento dos animais e das solicitações de interesse.

## Objetivos

O sistema tem como principais objetivos:

- disponibilizar um catálogo público de animais;
- permitir pesquisa e filtros por características;
- exibir informações detalhadas de cada animal;
- permitir o registro de interesse em adoção;
- disponibilizar uma área administrativa autenticada;
- permitir cadastro, edição, exclusão e atualização dos animais;
- permitir o acompanhamento das solicitações de adoção;
- armazenar os dados em banco de dados relacional.

Nesta entrega parcial, o projeto contém:

- `index.html` — protótipo da interface pública;
- `img/` — imagens utilizadas no protótipo;
- `database/schema.sql` — estrutura inicial do banco de dados.

## Arquitetura

O projeto foi planejado utilizando arquitetura multicamadas inspirada em MVC, com separação entre:

- camada de apresentação;
- rotas e controladores;
- regras de negócio;
- persistência de dados;
- banco de dados relacional.
